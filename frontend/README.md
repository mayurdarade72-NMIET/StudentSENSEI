# StudentSENSEI

StudentSENSEI is a personalized and gamified study planner designed to help students plan their studies, stay focused, track their progress, and receive AI-powered study guidance.

## Vision

Plan → Study → Track → Reward → Analyze → Improve

## Core Features

- Personalized study planning
- Daily study tasks
- Pomodoro focus timer
- Study-time tracking
- XP, points, levels, and streaks
- Daily and weekly progress reports
- AI-powered study assistant
- Gamified student experience
